# TDP-talleres

Trabajos desarrollados en C++ por Amaru Monje Rojas para la asignatura Taller de Programación (1-2024, USACH).

Cada carpeta contiene el código fuente, archivos de prueba y el informe del taller.

## Contenido

- **Taller 1 (`Taller1/`)**: Solución al N-Puzzle usando búsqueda A* con tabla hash y min-heap propios. Código fuente en `Taller1/Código/`, tableros de prueba e informe en `Informe1.pdf`.
- **Taller 2 (`Taller2/`)**: Búsqueda del clique máximo en un grafo usando el algoritmo de Bron-Kerbosch con pivote. Incluye grafos de prueba e informe en `informe.pdf`.
- **Taller 3 (`Taller3/`)**: Solución al problema de la mochila (Knapsack Problem) usando Simplex y Branch and Bound. Incluye casos de prueba, notas en `readme.txt` e informe en `informe.pdf`.

## Compilación y ejecución

Desde la carpeta donde está el `makefile` de cada taller (`Taller1/Código/`, `Taller2/` y `Taller3/`):

```bash
make
./main
```
